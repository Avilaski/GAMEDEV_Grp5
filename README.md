# Bomberman Rhythm Ultra
Made by Adrian Patrick Bacolod, Christen Cielo Infante, Greg Avila Jr., and Gianela Kim Agsalon

## About this game
Bomberman Rhythm Ultra is a rhythm game based off the retro action game Bomberman. (WIP)


## Controls
**A** - Move to first (top/left) lane  
**S** - Move to second (middle) lane  
**D** - Move to third (bottom/right) lane  
**Space** - Plant a bomb
